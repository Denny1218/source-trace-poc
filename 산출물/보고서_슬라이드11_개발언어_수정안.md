## 슬라이드 본문 (교체용)

**제목:** 개발 결과물과 사용 언어·기술  
**부제:** 서버와 Client 산출물에 사용한 언어·기술을 정리했습니다.

### 1. 서버 Backend
- **언어:** Python
- FastAPI, SQLite, Git CLI
- Diff 수집 · PPT Parser (`python-pptx`)
- Ollama HTTP Client (선택)

### 2. Web 화면
- **언어:** TypeScript (React + Vite)
- 장비 관리, Git 변경 이력, 변경내역서 분석
- Source Trace 조회 (함수/선택 코드)

### 3. VS Code Extension
- **언어:** TypeScript
- VS Code API, VSIX
- Markdown 결과 + Preview

### 4. Eclipse Plug-in
- **언어:** Java 17
- Eclipse Plug-in (OSGi)
- Backend API 호출 · 결과 표시

### 5. Visual Studio Extension
- **언어:** C# / .NET Framework
- VS2010(.NET 4.0) · VS2017(.NET 4.6) · VS2022(.NET 4.7.2) **각각 별도 VSIX**
- Backend API 호출 · 결과 표시

### 6. AI 보조 (선택)
- **플랫폼:** Local LLM / Ollama
- Git·PPT **후보 검색·근거 연결은 서버 Rule** (임베딩 RAG 아님)
- Ollama는 근거가 있을 때만 **요약 문장 보조** (기본 OFF)

**하단 한 줄:**  
제출·운영·재사용 관점에서 서버 패키지, IDE Client, Web 화면, 설치/운영 가이드, 명세를 함께 정리했습니다.
