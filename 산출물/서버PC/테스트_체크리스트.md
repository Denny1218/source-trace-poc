## API (PowerShell)

- [ ] `POST /api/trace/search` — Candidate에 `repository_id`, `repository_name` 포함
- [ ] `POST /api/trace/ppt-candidates`
- [ ] `POST /api/trace/ppt-analysis`
- [ ] `POST /api/trace/report` — Extension 함수/Symbol 변경 이력 조회 (200 OK)
- [ ] `POST /api/trace/selection` — Extension 선택 코드 변경 근거 조회 (PROJECT_SPEC v2.6)
      - `equipment_id` + `repo_relative_path` 로 조회 성공 (`repo_id_hint` 선택)
      - Extension remote URL 매칭 실패가 Backend 호출을 막지 않음
      - 공통 `resolve_equipment_repository` 사용
      - 동일 상대경로가 ready Repo 2개 이상이면 ambiguity 오류
      - 구버전 `file_path` / `repo_id` fallback 동작 (deprecated)
      - `..` path traversal 거부
      - Remote 절대경로와 서버 clone 경로가 달라도 repo-relative 계약으로 성공
      - 선택 코드가 서버 revision(`git show`) 해당 행과 일치할 때만 blame / log -L 수행
      - 불일치 시 과거 Commit 미제시 + 「선택한 코드와 서버 Git 소스가 일치하지 않습니다」안내
- [ ] `POST /api/trace/report` — 함수 이력 단순 결과
      - 한눈에 보기: 최초 확인 / 이후 Git 이력 / 관련 문서 / 조회 파일
      - 변경 상세: Commit 메시지와 `코드에서 확인`(Diff 사실) 분리, 추측성 문장 없음
      - 관련 문서: `관련 소스·함수 보기` (연결 Commit 미표시)
      - 변경 이력 3열 (날짜·Commit·변경 내용), 의미 분류 섹션 없음
      - 관련 문서 단일 섹션 (연결 유형/신뢰도 미표시)
      - Diff 미확인 Commit은 `(대상 함수 Diff 미확인)` 표기
      - Markdown 관련 함수/소스: 조회 대상 우선 표시 + `외 N개` (Evidence Link는 전체 목록)
