# 운영 PC — Browser 및 API 테스트 가이드

> **제출용 통합 사용 매뉴얼(권장)**  
> 서버 설치부터 Web·IDE 전체 절차 → **`SourceTrace_POC_전체_사용_매뉴얼.md`**

> **사용자 절차 요약**  
> 서버가 이미 설치된 뒤 Web/VS Code 절차만 → **`사용자_사용_매뉴얼.md`**

## 이 폴더 용도

**운영 담당자 PC**에 복사합니다.  
서버 소프트웨어 설치는 **하지 않습니다**. Browser와 테스트 스크립트만 사용합니다.

> **파일명 안내**: 실행 스크립트·설정(`server_host.txt`, `api_test.ps1`, `open_browser.bat`)만
> 영문 파일명을 사용합니다. PowerShell 5.x / CMD 호환을 위함입니다. 안내 문서(`.md`)는
> 한글 파일명을 그대로 사용합니다.

## 사전 준비

1. `server_host.txt`에 내부망 서버 IP 입력 (예: `192.168.10.50`)
2. 서버 PC에서 `03_서버시작.bat` 실행 중인지 확인
3. 운영 PC → 서버 **8010 포트** 네트워크 접근 가능 확인

## Browser 접속

```text
http://<서버IP>:8010
```

또는 `open_browser.bat` 실행

## Web UI에서 확인할 탭

| 탭 | 확인 내용 |
|---|---|
| 시스템 상태 | Backend/DB/Git 연결 |
| 장비 관리 | 장비 등록 → Git Repository 추가 (Yona URL 또는 Local) |
| Git 변경 이력 | Git Commit 조회, Repository 필터, 동기화 Loading |
| 변경내역서 분석 | 변경내역서 분석, Cache 목록/상세 |
| Source Trace 조회 | 함수 변경 이력, 선택 코드 변경 근거 조회 |

## 장비 등록 흐름 (운영 담당자)

1. 장비명 + 변경내역서 **UNC** 경로 등록 (Windows 탐색기에서 복사·붙여넣기 — **운영 PC 로컬 폴더 아님**)
   - **[경로 확인]**으로 PPTX 개수 검증
2. 장비 **추가/수정** 화면에서 Git Repository 추가 (0개 허용)
3. Remote 선택 시 Yona Git URL **그대로** 붙여넣기 (URL Username은 무시, 서버 `YONA_DEFAULT_USERNAME` 사용)
4. 연결 확인(선택) → 저장 → Repository 준비 상태 확인 → Git 동기화

Git 변경 이력/변경내역서 분석/Source Trace 조회는 다른 Tab으로 이동했다가 돌아와도 기존 결과를 유지하며 자동 재실행하지 않습니다.

## 주의

- Browser에서 `localhost:8010`은 **운영 PC 자신**을 가리킵니다. 반드시 **서버 IP** 사용
- Node.js 설치 불필요

## VS Code에서 바로 조회하고 싶다면 (선택)

Web UI 대신 VS Code에서 함수명을 선택한 채로 바로 변경 이력을 조회하고 싶다면
`VSCode-Extension\` 폴더를 참고하세요. `.vsix` 설치 파일과 가이드가 포함되어 있으며,
서버 설치와는 무관하게 **개인 PC의 VS Code**에 설치하는 선택 사항입니다.

Web `Source Trace 조회`와 IDE Client(VS Code / Eclipse / VS2017 / VS2010)는 모두 같은 Backend 공식 결과를
조회하는 경로입니다. Continue 연동은 공식 범위가 아닙니다.

## IDE 클라이언트 (선택)

| Client | 공식 설치 파일 |
|---|---|
| VS Code | `VSCode-Extension\source-trace-vscode-0.5.4.vsix` |
| Eclipse | `eclipse\source-trace-eclipse-update-site-0.1.1.zip` |
| Visual Studio 2017 | `visualstudio\source-trace-visualstudio2017-0.1.3.vsix` |
| Visual Studio 2010 | `visualstudio\source-trace-visualstudio2010-0.1.3.vsix` |
