# 운영 PC 테스트 체크리스트

## 네트워크

- [ ] `server_host.txt`에 서버 IP 입력
- [ ] `open_browser.bat` — Health OK 후 Browser 열림

## Browser UI (`http://<서버IP>:8010`)

- [ ] 시스템 상태 — Backend 연결 ok
- [ ] 장비 관리 — UNC 경로 직접 입력 + 경로 확인, Git Repository 추가 (장비 추가 화면 포함)
- [ ] Git 변경 이력 — 검색/동기화 중 Loading Panel 및 경과 시간
- [ ] 변경내역서 분석 — 분석 실행, Cache 목록/상세, Tab 이동 후 분석 상태 유지
- [ ] Source Trace 조회 — 함수 조회/선택 코드 조회, 결과 복사, 내부 STEP/AI 용어 미노출

## API (선택)

- [ ] `api_test.ps1` 실행 — Health, Trace, PPT API
  ```bat
  powershell -ExecutionPolicy Bypass -File api_test.ps1
  ```

## Cache Hit (2회 분석)

- [ ] 변경내역 분석 탭에서 동일 조건 2회 분석
- [ ] 2회차 `cache_hits` 증가 확인 (또는 서버 로그)

## VS Code Extension (선택)

- [ ] `VSCode-Extension\` 폴더의 `테스트_체크리스트.md` 참고
- [ ] Web `Source Trace 조회`와 IDE Client가 같은 Backend 공식 결과를 보여줌을 확인 (별도 AI 채팅 도구 연동 없음)

## 확인하지 않는 항목 (이번 패키지 기본)

- Trace Search 전용 Web UI (없음 — API만)

## 문제 시

서버 담당자에게 전달:

- 서버 IP, 시간대
- Browser F12 Network 오류
- `api_test.ps1` FAIL 항목
