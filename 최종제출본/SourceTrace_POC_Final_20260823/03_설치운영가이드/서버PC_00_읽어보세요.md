# 서버 PC — 설치 및 테스트 가이드

## 이 폴더 용도

내부망 **서버 PC**에 복사하여 Backend + Web UI를 실행합니다.  
Node.js는 **필요 없습니다**.

## 사전 요구 사항

- Python 3.12, Git CLI
- 변경내역서 `document_path`: **UNC 네트워크 공유 경로** (예: `\\server\share\HHD200`)
- Yona Remote: Git Credential Helper에 Read 권한 계정 등록

## 기존 서버에 덮어쓸 때

제출본/ZIP을 **이미 운영 중인 `deploy` 위에 복사하면** 빈 `equipment_change_trace.db`가
운영 DB를 덮어쓸 수 있습니다. 아래는 **복사하지 마세요.**

- `.env`
- `data\*.db`, `data\*.db-wal`, `data\*.db-shm`
- `backend\data\*.db` 및 `-wal`/`-shm`

코드·프론트만 갱신하고, DB는 서버에 있는 파일을 그대로 둡니다.

## 설치 순서

1. `deploy\` 복사 (기존 서버면 위 DB/`.env` 제외)
2. `.env.example` → `.env`
   - `DATABASE_PATH` 설정
   - `YONA_DEFAULT_USERNAME=source_trace` (필수 — Remote Git Access)
3. **Yona Credential (최초 1회):** `scripts\setup-yona-credential.bat <host:port> [username]`
4. `01_env_check.bat` → `02_offline_install.bat` → `03_start_server.bat`
5. 상태 확인: `04_status_check.bat` (또는 `04_상태확인.bat`)
6. 중지: `05_stop_server.bat` (또는 `05_서버중지.bat`) → 재시작은 중지 후 `03_start_server.bat`

## 장비 등록

1. 장비명 + **UNC** 변경내역서 경로 (Windows 탐색기에서 복사·붙여넣기 + **경로 확인**)
2. Git Repository 추가 (장비 추가/수정 화면, 설정 저장 후 준비 단계 분리)
3. Git 동기화

상세: `OPERATING_TEST_STEP6.md`
